# OverChat 0.6.0 — разработка

## Архитектура

- `src-tauri/src/lib.rs`: команды Tauri, запуск, одна копия, закрытие в трей.
- `overlay.rs`: сквозные клики, показ без фокуса, проверка доступности сохранённой позиции, восстановление окна, удержание поверх безрамочных игр каждые 500 мс.
- `settings.rs`: настройки в `%APPDATA%/app.overchat.desktop/settings.json`, ограничения значений, миграция режима для игр из 0.5.
- `hotkeys.rs`: глобальные Ctrl+Shift+X и Ctrl+Shift+H, смена сочетаний.
- `tray.rs`: открыть настройки, показать чат, сквозные клики, вернуть чат на экран, выход.
- `twitch/mod.rs`, `irc.rs`: анонимное чтение IRC по WebSocket, повторное подключение, отдельный таймер отсутствия ответа.
- `twitch/emotes.rs`: Twitch и 7TV, включая наложенные смайлики.
- `src/settings`: интерфейс настроек; `src/overlay`: рендер сообщений.

OAuth, Client ID, Helix и чтение токенов удалены. Значки ролей отображаются буквами. Поля старого файла настроек, относящиеся к входу, игнорируются.

## Сборка и проверки

Нужны Windows x64, Node.js 20+, Rust MSVC, Build Tools for Visual Studio и WebView2.

```powershell
npm ci
npm run app:dev
npm run build
cargo test --offline --manifest-path src-tauri/Cargo.toml
npm run app:build
```

Выход: `src-tauri/target/release/overchat.exe` и `src-tauri/target/release/bundle/nsis/OverChat_0.6.0_x64-setup.exe`.
Тесты с реальными серверами: `cargo test --manifest-path src-tauri/Cargo.toml -- --ignored`.

## Проверка оверлея

1. На чистом профиле открываются настройки и окно чата, видны демо-сообщения.
2. Подключение к каналу работает без входа; демо выключается, старые сообщения очищаются.
3. Ctrl+Shift+X переключает сквозные клики, Ctrl+Shift+H скрывает/показывает чат без смены фокуса.
4. В безрамочной игре режим для игр удерживает чат сверху.
5. «Вернуть чат на экран» возвращает окно на основной монитор и выключает сквозные клики.
6. После отключения монитора сохранённое окно вне оставшихся экранов переносится на основной монитор.
7. Проверить установщик, запуск установленного приложения, трей, повторный запуск и выход.

Для Fortnite: Настройки → Видео → Режим окна → «Оконный полноэкранный» (Windowed Fullscreen).
Эксклюзивный полноэкранный режим не поддерживается. Проверка геометрии и сборки не заменяет испытание в настоящей игре; FPS и совместимость с конкретными античитами не измерялись для 0.6.0.
