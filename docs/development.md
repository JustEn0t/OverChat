# OverChat

Чат Twitch поверх игры для Windows — по назначению похож на RutonyChat.
Сейчас это **версия 0.5.1**: чат любого канала по нику (без входа), смайлики Twitch и 7TV,
окно поверх всех окон со сквозными кликами, режим для безрамочных игр, настраиваемые
горячие клавиши, внешний вид (шрифт, размер, компактный режим, прозрачность), фильтр команд,
автоскрытие старых сообщений, значок в трее, автозапуск с Windows и предупреждение об
эксклюзивном полноэкранном режиме. Вход в Twitch — необязательный, только ради картинок значков.

## Стек и почему он

| Слой | Выбор | Почему |
|---|---|---|
| Оболочка | **Tauri 2** (Rust) | Маленький установщик (~2 МБ): браузерный движок не встраивается, используется системный WebView2. Нативно умеет прозрачные окна без рамки, «поверх всех» и сквозные клики (`set_ignore_cursor_events` → `WS_EX_TRANSPARENT`). Встроенная сборка NSIS-установщика. Замеры нагрузки — в разделе «Проверка в играх». |
| Интерфейс | TypeScript + Vite, без фреймворка | Два маленьких окна — фреймворк не нужен. Рендер через WebView2 (уже есть в Windows 10/11). |
| Горячие клавиши | `tauri-plugin-global-shortcut` | Системный `RegisterHotKey` — работает, когда фокус в игре, без хуков клавиатуры. |
| Настройки | `settings.json` в `%APPDATA%\app.overchat.desktop` | Один источник правды в Rust; запись через временный файл, поэтому сбой не портит настройки. Позиция и размер окон — `tauri-plugin-window-state`. |
| Режим для безрамочных игр | `SetWindowPos(HWND_TOPMOST, SWP_NOACTIVATE)` раз в 1,5 с | Только для собственного окна: возвращает чат наверх, не забирая фокус у игры. |
| Эксклюзивный полноэкранный режим | `SHQueryUserNotificationState` раз в 1,5 с | Та же проверка, по которой Windows придерживает уведомления. Только чтение, к игре не обращается. |
| Трей, автозапуск, одна копия | `tray-icon`, `tauri-plugin-autostart` (HKCU\…\Run, `--minimized`), `tauri-plugin-single-instance` | Чат живёт без окна настроек; повторный запуск открывает настройки уже работающей копии, а не второй оверлей. |
| Чат | **Twitch IRC через WebSocket, анонимно** (`justinfan…`) | Читать открытый чат можно без входа и регистрации — достаточно ника канала. Теги IRC дают цвет, значки, отображаемое имя и позиции смайликов Twitch. |
| Смайлики | Twitch CDN + **7TV API v3** | Смайлики Twitch — по позициям из тега `emotes`; 7TV — глобальные и канала, по словам; «наложенные» (zero-width) рисуются поверх предыдущего смайлика. Вход не нужен. |
| Значки-картинки (необяз.) | OAuth **Device Code Flow** + Helix | Twitch отдаёт картинки значков только вошедшим приложениям. Без входа значки — цветные буквы. |
| Токены | Диспетчер учётных данных Windows (`keyring`) | Зашифрованы Windows для текущего пользователя; не лежат в файлах и не попадают в WebView. |
| Установщик | NSIS через `tauri build` | Ставится в профиль пользователя без прав администратора, ярлык в «Пуске», деинсталлятор. |

**Ограничения Windows.** Окно «поверх всех» видно в **оконном** и **безрамочном оконном**
режимах игры. В **эксклюзивном полноэкранном** режиме игра владеет экраном, и Windows может
не показывать чужие окна — приложение пишет об этом пользователю на экране настроек.
OverChat — обычное отдельное окно: не внедряется в процесс игры, не рисует через DirectX-хуки
и не читает память, поэтому не конфликтует с античитами.

## Архитектура

```
┌──────────────────────────── Rust (src-tauri/src) ────────────────────────────┐
│ lib.rs          команды, запуск, закрытие в трей, автозапуск                 │
│ tray.rs         значок в трее и его меню                                     │
│ settings.rs     settings.json: загрузка, проверка значений, сохранение       │
│ overlay.rs      сквозные клики, показать/скрыть без фокуса, режим для игр,   │
│                 обнаружение эксклюзивного полноэкранного режима              │
│ hotkeys.rs      две глобальные клавиши, смена на лету, пауза при записи      │
│ twitch/mod.rs   две фоновые задачи: чат и (необяз.) вход; статусы, команды   │
│ twitch/irc      анонимный IRC: JOIN, ROOMSTATE → id канала, PRIVMSG, PING    │
│ twitch/emotes   7TV (глобальные + канала), разбор смайликов → fragments      │
│ twitch/badges   картинки значков из Helix (только при входе)                 │
│ twitch/auth     Device Code Flow, validate, refresh, revoke                  │
│ twitch/store    токены в Windows Credential Manager                          │
└───────▲───────────────────────────────┬──────────────────────────────────────┘
        │ invoke (update_settings,      │ события settings-changed, chat-message,
        │  chat_connect, …)             │ chat-delete, chat-status, account-status,
        │                               │ click-through-changed, overlay-visibility
┌───────┴──────────┐   событие   ┌──────▼────────────────────┐
│ Окно «main»      │ ──────────▶ │ Окно «overlay»            │
│ настройки        │ chat-message│ прозрачное, без рамки,    │
│ (index.html)     │ (тест)      │ поверх всех, без панели   │
│                  │             │ задач (overlay.html)      │
└──────────────────┘             └───────────────────────────┘
```

Настройки меняет только Rust: окно настроек отправляет `update_settings`, Rust проверяет
значения (и регистрирует новые горячие клавиши), сохраняет файл и рассылает
`settings-changed` — оверлей сразу применяет шрифт, размер, прозрачность и остальное.

Тестовое сообщение и настоящий чат приходят в оверлей одним и тем же событием `chat-message`.
Сообщение — это список фрагментов: текст и смайлики (`{type: "emote", url, zeroWidth}`).

### Подключение к чату

1. Пользователь вводит ник или ссылку `twitch.tv/ник` → `wss://irc-ws.chat.twitch.tv`,
   анонимный логин `justinfanNNNNN`, `JOIN #ник`.
2. `ROOMSTATE` даёт числовой id канала. Если его нет за 10 с — «Канал не найден».
3. Параллельно загружаются смайлики 7TV (`/v3/emote-sets/global` и `/v3/users/twitch/{id}`)
   и, если пользователь вошёл, значки из Helix → статус «Подключено · 7TV: N смайликов».
4. Модератор удалил сообщение (`CLEARMSG`), дал бан/таймаут (`CLEARCHAT` с id пользователя)
   или очистил чат → оверлей убирает эти сообщения, как и сам чат Twitch.
5. Обрыв сети или `RECONNECT` от Twitch → «Переподключение…» с причиной и паузой 1→2→4…60 с.
6. Последний канал запоминается, и при запуске приложение подключается к нему само.

### Необязательный вход (картинки значков)

«Войти через Twitch» → Device Code Flow (код подтверждается на twitch.tv в браузере) →
токены в Credential Manager → чат переподключается уже с картинками значков. Токен
проверяется при запуске и при каждом подключении, истёкший обновляется сам, отозванный
удаляется — значки снова становятся буквами.

## Запуск

Нужны Node.js 20+ и Rust (MSVC). Один раз: `npm install`.

- Режим разработки (с перезагрузкой интерфейса): `npm run app:dev`
- Сборка exe и установщика: `npm run app:build`
  - установщик: `src-tauri/target/release/bundle/nsis/OverChat_0.5.1_x64-setup.exe`
  - сам exe без установки: `src-tauri/target/release/overchat.exe`
- Тесты Rust: `cd src-tauri` → `cargo test`; проверки на настоящих серверах Twitch и 7TV:
  `cargo test -- --ignored`.

## Как пользоваться

1. Запустите OverChat — откроются окно настроек и окно чата слева.
2. Введите ник канала (или вставьте ссылку на него) и нажмите **Подключить**.
   Демо-поток выключится сам, и в оверлее пойдут сообщения чата со смайликами.
3. Пока сквозные клики выключены, окно чата обведено пунктиром: тяните за фиолетовую
   полоску, чтобы переместить, и за уголок справа внизу, чтобы изменить размер.
4. Включите **Сквозные клики** (или нажмите **Ctrl+Shift+X**) — рамка исчезнет,
   клики пойдут в игру. Та же клавиша возвращает управление чатом.
   **Ctrl+Shift+H** быстро скрывает и возвращает чат, не забирая фокус у игры.
5. Если игра в режиме «Без рамки» перекрывает чат, включите **Режим для безрамочных игр**.
6. **Внешний вид**: прозрачность фона, шрифт, размер текста, компактный режим (без времени,
   плотнее строки), сколько сообщений держать на экране и через сколько скрывать старые.
   Когда все сообщения скрылись, при включённых сквозных кликах фон тоже исчезает.
7. **Фильтры**: «Скрывать команды» убирает сообщения вида `!discord`.
8. **Горячие клавиши** меняются прямо в окне настроек: нажмите кнопку, затем сочетание.
   Если сочетание занято другой программой, OverChat скажет об этом и оставит прежнее.
9. Положение и размер окон, канал и все настройки сохраняются; при следующем запуске
   чат подключится сам.
10. **Трей.** Закрытие окна настроек прячет его в трей — чат продолжает работать.
    Левый клик по значку открывает настройки, правый — меню: показать чат, сквозные клики,
    выход. Windows 11 прячет новые значки под стрелку «^»: перетащите значок OverChat на панель
    задач, чтобы он был всегда виден.
11. **Автозапуск.** «Запускать вместе с Windows» — OverChat стартует сразу в трей и подключается
    к последнему каналу.

## Установка и SmartScreen

Установщик не подписан цифровой подписью (для этого нужен платный сертификат подписи кода),
поэтому при первом запуске Windows может показать «Windows защитила ваш компьютер».
Нажмите **Подробнее → Выполнить в любом случае**. Установка идёт в профиль пользователя,
права администратора не нужны.

## Проверка в играх

### Что проверено автоматически (версия 0.5)

| Проверка | Результат |
|---|---|
| Безрамочная «игра» (окно без рамки на весь экран, поверх всех) перекрывает чат без режима для игр | да — чат закрыт |
| То же с **режимом для безрамочных игр** | чат сверху в 10 из 10 замеров, фокус у чата не переходит |
| Горячие клавиши, пока фокус в другом окне | работают, фокус не забирают |
| Сквозные клики | клик в области чата получает окно под ним |
| Нагрузка, медленный чат (тестовые сообщения со смайликами) | ~4 % одного ядра |
| Нагрузка, чат скрыт (Ctrl+Shift+H) | ~1 % одного ядра |
| Нагрузка, очень быстрый чат (xqc), анимированные смайлики | ~23 % одного ядра (1,2 % CPU на 20 потоков) |
| То же, анимация смайликов выключена | ~8,5 % одного ядра (0,4 % CPU) |
| Память (OverChat + процессы WebView2) | ~265 МБ |

Основная нагрузка — отрисовка анимированных смайликов 7TV в прозрачном окне (процессы
WebView2 GPU и renderer), а не скорость чата. На слабом ПК: выключите «Анимированные смайлики»,
уменьшите «Сообщений на экране» или включите «Скрывать сообщения через…».

### Чек-лист для проверки в настоящей игре

1. Запустите игру в режиме **«Без рамки» / «Полноэкранный в окне»**. Чат должен быть виден.
   Если игра перекрывает чат после клика в неё — включите «Режим для безрамочных игр».
2. Включите сквозные клики, кликните и постреляйте в области чата — управление у игры.
3. Нажмите горячие клавиши внутри игры: игра не должна сворачиваться или терять фокус.
4. Переключите игру в **эксклюзивный полноэкранный** режим: чат пропадёт — это ограничение
   Windows. Значок в трее и окно настроек покажут подсказку переключиться в «Без рамки».
5. Посмотрите FPS с чатом и без (Ctrl+Shift+H скрывает чат).

### Античиты

OverChat не внедряется в процесс игры, не использует DirectX-хуки, не читает память и не ставит
драйверы — это обычное отдельное окно, как Discord или OBS-предпросмотр поверх игры.
Гарантировать поведение каждого античита нельзя: если игра с жёстким античитом (например,
FACEIT AC, Vanguard) пожалуется, сообщите — проверим, на что именно.

### Картинки значков (необязательно)

Без входа значки показываются цветными буквами (B — стример, M — модератор, V — VIP,
S — подписчик). Чтобы видеть настоящие картинки значков Twitch:

1. Откройте https://dev.twitch.tv/console/apps → **Register Your Application**.
2. Название — любое, OAuth Redirect URL — `http://localhost`,
   категория — *Application Integration*, **Client Type — Public** («Публичный»).
3. Скопируйте **Client ID**, раскройте в OverChat блок «Значки-картинки Twitch»,
   вставьте его и нажмите **Войти через Twitch**. Секрет не нужен.

Client ID можно вшить в сборку, чтобы поле не показывалось:
`$env:TWITCH_CLIENT_ID = "ваш_id"; npm run app:build`.
